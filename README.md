# Read Out To (.) me

Web Application for accessible text to speech online.

## Run the application

Install Deno by following the [official instructions](https://docs.deno.com/runtime/getting_started/installation/).

Execute in the project folder:

```bash
deno install
deno run --allow-net --allow-read=public src/server.ts
```

The application will be running on [localhost:8080](http://localhost:8080/)
